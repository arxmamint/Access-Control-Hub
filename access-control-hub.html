Cybersecurity GRC — UAR · PAR · JML

UAR Overview

Who has access to which system, reviewed by the system owner.

Access by System

Select a system to see exactly who has access. Add or edit staff access entries inline.

PAR Overview

Every privileged item is accountable to exactly one person.

Privileged Assets by Category

Servers & Hosting, Network Equipment, and SaaS — each with one accountable owner.

Rule: each asset must have exactly one accountable person. Rows missing an accountable person are flagged in the overview.

Sample demonstration data only. Nothing is saved between visits.

Department View — Head of Department

Select your department to see all your staff and what they can access. As HOD you can add staff, grant systems, edit access levels, or revoke access — changes reflect immediately in the UAR and Staff views.

Each staff card lists their systems with access level. "Revoke" removes the access record from UAR; the system dropdown adds a new access grant.

Staff Access Directory

All staff consolidated from the UAR tables. Click a staff member to see every system they can access (UAR), any privileged assets they are accountable for (PAR), and their JML movement status — all in one place.

JML Overview

Joiner, Mover and Leaver cases. Each case lists the systems that staff can access and each system owner's action status.

Movement Cases

For leavers and movers: every system the staff can access must have its account disabled / realigned by the system owner. Update each system's status from the dropdown.

Per-system statuses: Active · Have Disabled — Pending Approval · Disabled — Approved · Pending Collection (joiner provisioning) · Revoked (mover) · Keep (mover)
